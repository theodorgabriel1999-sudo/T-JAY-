# Release checklist

- [ ] Build/test on clean M1, M2, M3, M4 and M5 Macs.
- [ ] Test macOS 14 Sonoma and newer supported releases.
- [ ] Verify Intel hardware is blocked.
- [ ] Test missing Homebrew and failed installs/verifications.
- [ ] Review component source, license, commercial-use terms and dependencies.
- [ ] Add cancellation, timeout, rollback, uninstall and repair.
- [ ] Add app icon, accessibility, privacy notice, EULA and support contact.
- [ ] Obtain Developer ID Application certificate.
- [ ] Store notarization credentials in Keychain using notarytool.
- [ ] Sign, notarize, staple and test DMG with Gatekeeper on a clean Mac.
- [ ] Publish checksums, release notes and third-party notices.
- [ ] Clear product name/trademark before commercial sale.
